The default event rotation, one row per event. Changes are saved to the rotation template. Use “Apply now” (top right) to push them to a running server, otherwise they apply the next time it starts.

Cup settings are saved to the cup config. The game's own cup rotations can't be edited, so Customize events makes your own copy for that cup (starting with the cup's tracks, with settings taken from the main rotation).

Tick a setting to make it the default for every event in the main rotation and in your own cups. A field that follows a default shows Global (or Cup) on the Rotation and Cups tabs; click it there to override it for just that event, and use the ↩ next to it to follow the default again. A cup's own settings win over Global for that cup. Unticked settings leave each event's own value alone. Changes apply the next time the server starts, or use “Apply now” (top right) on a running server.

Is it working?

The server tests this itself a few seconds after it starts and prints the result in its window. This page only reads what the server said; it cannot test your router from outside. Playing on your own home network needs no forwarding.

Game version

Stops the server, then downloads the latest version of the server from Steam.

Players and the server must be on the same game version, or players are refused when they join. Wreckfest 2 is in Early Access and updates often: update the server whenever the game updates.
